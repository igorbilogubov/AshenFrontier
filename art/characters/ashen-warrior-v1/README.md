## Происхождение и права

Основа тела, шлема, брони, текстуры и скелет: **Paladin J Nordstrom**, каталог **Adobe Mixamo**, вариант без реквизита. Исходная модель скачана в T-pose из аккаунта пользователя 14 сентября 2026. Анимации тоже взяты из Mixamo для того же персонажа. Это доработанная библиотечная модель, а не полностью оригинальный персонаж, созданный с нуля.

Меч, топор, небольшой щит и короткий бордовый плащ созданы в Blender скриптом этого проекта. Подготовка материалов, разделение сапог, привязка нового снаряжения к костям, удаление горизонтального root motion, сборка клипов и GLB-экспорт выполнены здесь.

[Официальный FAQ Mixamo](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) описывает использование моделей и анимаций в личных и коммерческих проектах, включая игры. Применяются условия Adobe/Mixamo; это **не CC0**. Исходные FBX находятся в `source/` для работы над игрой; не публиковать их как самостоятельную библиотеку или товар. В браузер выдаётся только собранная игровая модель. Three.js и добавленные GLTFLoader/SkeletonUtils используются по MIT, как локальная версия Three.js 0.186.0.

## Сборка и редактирование

Проверено в Blender **5.2.1 LTS** на macOS. Из корня проекта:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python scripts/blender/build_warrior.py
npm run art:preview
npm test
```

Скрипт открывает отдельную пустую фоновую сцену, читает архивные FBX и перезаписывает производные `.blend`, `.glb`, отчёт и контрольный PNG. Ручные изменения в готовом `.blend` нужно сохранять под новым именем или переносить в скрипт перед повторной сборкой. Сцена содержит камеру и студийный свет, активен Idle, топор скрыт только в Blender для начального рендера. В Action Editor доступны семь Actions; одноимённые NLA tracks служат экспорту. Для просмотра выбранного Action треки должны оставаться muted.

67 костей, около **15,8 тыс. треугольников** с обоими вариантами оружия, встроенные текстуры 1024×1024, GLB около **4 МБ**. UV и веса исходной брони сохранены. Модель ориентирована вперёд по +Z в Three.js; в игре равномерно увеличена в 1,12 раза.

Именованные части: `Helmet`, `Armor_Body`, `Boots`, `Cape`, `Weapon_Sword`, `Weapon_Axe`, `Weapon_Buckler`. Щит — часть визуального комплекта оружия, дополнительных слотов/характеристик он не добавляет. Существующие шесть слотов основной игры (оружие, доспех, шлем, сапоги, кольцо, амулет) не менялись. Полное визуальное переодевание из онлайн-инвентаря ещё не подключено.

## Работа в игре

`public/game/character.ts` загружает GLB через GLTFLoader и смешивает клипы AnimationMixer. Цикл шага зависит от пройденного расстояния, Walk/Run и переход в стойку смешиваются. Удар синхронизирован с игровой атакой: урон в 49% её длительности совпадает с выходом клинка вперёд (50% исходного поперечного клипа, 44,5% удара сверху). Меч чередует два удара, топор использует удар сверху. Баланс урона/дистанции/перезарядки прежний.

Реакция на урон накладывается на верх тела, не меняя цикл ног, и не перебивает удар. Падение останавливается на последнем кадре; после возрождения веса сбрасываются в стойку. В самой игре нет вращения камеры; ракурс меняется только в отдельной мастерской.

Ограничения первой версии: плащ с весами на костях, без симуляции ткани; щит и оружие пока без детальных текстур; нет IK для склонов и лестниц; удары топора используют тот же набор захвата движения. Модель тела воина пока единственная: лучник и маг используют её с отдельным луком или посохом и временными клипами. Общий сервер и сохранения подключены 14 сентября; платежи отложены.

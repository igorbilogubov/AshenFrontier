# Коллекции лучника и мага

Производные Erika Archer и Dreyar By M.Aure (Adobe Mixamo), собственные оружие, украшения и детали одежды. Исходные FBX и `mixamo-classes-v1` не меняются. `build_class_equipment.py` читает готовые исходные Blend и перезаписывает **только** Blend, GLB, рендеры и отчёт `class-equipment-v1`. Изменения этой коллекции переносить в генератор до пересборки.

Лучник: Следопыт и Лесной страж. Маг: Послушник и Хранитель рун. У каждого класса два оружия, два доспеха/одеяния, два головных убора, две пары сапог и общие кольцо/амулет. Снятые вещи открывают закрытую базовую одежду; голова и кисти используют исходную текстурированную модель. Все альтернативы используют 67 исходных костей и семь клипов. Это визуальные коллекции без бонуса за комплект.

```
/Applications/Blender.app/Contents/MacOS/Blender -b -t 2 --python scripts/blender/build_class_equipment.py
/Applications/Blender.app/Contents/MacOS/Blender -b -t 2 --python scripts/blender/render_class_item_icons.py
```

Иконки рендерятся из экспортированных игровых GLB. Проверять их и переключение всех шести слотов в `/game/equipment-preview.html`. Права Mixamo сохраняются; источники не CC0, не для отдельной перепродажи. Генератор не читает сохранения героев.

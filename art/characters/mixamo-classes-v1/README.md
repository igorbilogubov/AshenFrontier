# Mixamo: модели трёх классов

15 сентября 2026. По запросу пользователя: Exo Gray для воина, Erika Archer (без встроенного лука) для лучника, Dreyar By M.Aure для мага; тяжёлый Paladin остаётся снаряжением воина. Источник — каталог https://www.mixamo.com/, аккаунт пользователя. FBX Binary, T-pose, со скелетом и текстурами. Эти исходники Adobe/Mixamo не CC0 и не предназначены для отдельной перепродажи/публикации.

Подготовка в Blender сохраняет UV и исходные веса, переносит геометрию в позу общего игрового скелета. Лицевые кости сводятся к голове; лицевая анимация сейчас не используется. Клипы берутся из ранее скачанной коллекции [Paladin](../ashen-warrior-v1/README.md). Генератор `scripts/blender/build_class_models.py` перезаписывает только производные `.blend`, `.glb`, рендеры и отчёт лучника/мага в этой коллекции. Модульного воина собирает отдельный build_warrior_equipment.py; архивный Paladin и FBX не меняет. Ручные правки производной сцены сначала переносить в генератор.

Сгенерированные модели проверять в браузере. Снятое снаряжение означает базовую одежду, а не обнажённое тело. У воина сохраняются шесть слотов и случайные свойства вещей; подбор модели не меняет класс существующего героя.

У Exo Gray исходно 112 костей, лицевые группы сведены к ближайшей общей кости; у каждого игрового героя одна палитра из 67 костей. У Dreyar исходные внутренние размеры в 10 раз больше: единицы нормализованы перед переносом вершин, а не масштабированием игрового мира. Исходные UV/веса сохранены; общий помощник — scripts/blender/mixamo_common.py.

GLB: воин 5,94 МБ со всеми вариантами, лучник 3,22 МБ / 20 526 треугольников тела, маг 1,93 МБ / 14 235. Текстуры до 1024 px, непрозрачные изображения JPEG 88. Файлы классов загружаются по необходимости; текстуры и геометрия клонов общие. Семь прежних клипов сохранены, но отдельные движения стрельбы/каста ещё предстоит подготовить. Лук/посох пока созданы кодом. Лучник/маг имеют цельный базовый костюм, их сменные коллекции вещей пока не сделаны.

Пересборка из корня проекта: `/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python scripts/blender/build_class_models.py`. Затем npm run check, npm test и браузерная проверка `/game/equipment-preview.html`.

# Комплекты снежной зоны и пустошей

По одному полному комплекту каждого класса на уровни 10 и 25: 36 основ, у каждой есть отдельная синяя версия с собственным ID и диапазонами. Бонусов за полный набор и модификаций навыков нет. Предметы свободно смешиваются по шести слотам.

Внешность использует утверждённые текстурированные силуэты Дозорного, Лесного стража и Хранителя рун, с отдельной холодной и медно-пепельной палитрой. Это варианты материалов существующих моделей, не новые уникальные скульпты. Клиент меняет только материалы надетых частей на собственном экземпляре персонажа; снятие возвращает исходные материалы, соседние герои не перекрашиваются. Исходные Mixamo/Blender/GLB не перезаписываются, их лицензии сохраняются.

`scripts/blender/render_regional_item_icons.py` читает экспортированные GLB и перезаписывает только 36 PNG в `public/game/item-icons/` и `icon-report.json` этой папки. Иконки показывают реальные части моделей с соответствующей палитрой. Не редактировать PNG вручную вместо генератора.

```
/Applications/Blender.app/Contents/MacOS/Blender -b -t 2 --python scripts/blender/render_regional_item_icons.py
```

Проверка: `/game/equipment-preview.html`, выбор региона и класса, смешанные слоты, снятие вещи и восстановление исходного цвета. Палитры определены в `public/game/regional-equipment-visuals.ts` и воспроизведены в генераторе иконок.

16 сентября проверены в браузере экспортированные части и PNG: обсидиановый воин, снежный охотник, редкий пепельный провидец. Выбор региона обновляет название коллекции и требования уровня; смена класса подбирает экипировку текущего региона. Серверные тесты проверяют уровень/класс, точные диапазоны, дроп трёх регионов и неизменность экземпляра после подбора/загрузки.

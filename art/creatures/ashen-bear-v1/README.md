# Пепельный медведь — собственный Blender-ассет

15 сентября 2026. Бурый лесной медведь для опушки и четвёртого загона Стадиума. Код подключения и модель подготовлены локально; эта запись сама по себе не означает публикацию production.

## Происхождение и файлы

Модель, окраска, встроенная текстура шерсти, скелет и все движения созданы скриптом проекта в Blender 5.2.1 LTS. Внешние модели, фотографии и библиотеки анимаций не использованы. Геометрические и двухзвенные IK-помощники переиспользованы из собственного `scripts/blender/build_creatures.py`; его исходник и прежние GLB не изменены. `wolf-v1-reference` сохранён.

- Генератор: `../../../scripts/blender/build_bear.py`.
- Рабочая сцена с Actions, NLA tracks, светом и камерой: `bear.blend`.
- Игровой экспорт: `../../../public/game/creatures/bear.glb`.
- Отчёт: `bear-report.json`; контрольный рендер: `renders/bear.png`.
- Общая мастерская: `/game/creature-preview.html`, пункт «Пепельный медведь».

У медведя широкие плечи с горбом, короткая морда и хвост, круглые уши и широкие лапы с пятью когтями. Основные объёмы объединены voxel remesh; мелкие пряди ограничены плечами и щеками. Шерсть передаётся переменной окраской `COLOR_0` и встроенной текстурой 256 × 256, без прозрачных волос и дополнительных проходов.

Экспорт содержит **21 286 треугольников**, **10 805 исходных вершин**, **24 кости**, **5 групп материалов**, **1 390 604 байта**. Все вершины имеют веса. Один набор геометрии и материалов переиспользуется клонами, каждый экземпляр имеет независимый скелет и AnimationMixer. Видимый размер стойки до игрового масштаба — около 0,95 × 1,53 × 2,33 м; `scale=1.15`, серверный `radius=.62`, дальность удара `1.6` заданы общим контрактом карты.

## Движения

| Клип | Длительность | Действие |
| --- | ---: | --- |
| Idle | 2,8 с | Спокойное дыхание и малые движения головы/ушей |
| Walk | 1,6 с | Четырёхтактный тяжёлый шаг, опора 70% цикла |
| Run | 0,9 с | Короткие диагональные шаги, опора 58% цикла |
| Attack | 1,2 с | Перенос веса, подъём правой передней лапы, взмах и возврат |
| Hit | 0,5 с | Небольшая реакция груди и головы |
| Death | 1,6 с | Падение на бок с поджатыми лапами |
| Turn_Left / Turn_Right | по 1,6 с | Переступание с удержанием опорных лап |

Клипы запечены при 30 FPS, вращения экспортированы кватернионами. Шаг использует длину полного цикла 0,72 м модели, бег — 1,00 м. Горизонтальная скорость лапы непрерывна на переходе опоры/переноса, подъём плавный; двухзвенный IK удерживает опору при раскачке корпуса. Фаза runtime зависит от фактического сглаженного перемещения, поворот — от изменения угла. Одна полная фаза поворота соответствует одному радиану.

Контакт взмаха задан на **68% Attack**, как у существующей серверной фазировки мобов. Подготовка занимает серверный `windup=1.08`, оставшиеся 32% проигрываются за 0,45 с восстановления. Клип не назначает урон; это делает сервер. Реакция Hit накладывается только на верх тела, не прерывая телеграф и опору.

## Пересборка

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python scripts/blender/build_bear.py
npm run check
npm test
```

Генератор перезаписывает только медвежьи `.blend`, GLB, отчёт и контрольный PNG. Ручные изменения сцены нужно перенести в генератор или сохранить отдельно до пересборки. `.blend1` — автоматическая копия, в Git не входит.

## Проверено и ограничения

`test/creatures.test.mjs` загружает реальные экспортированные скелеты: бюджет, все восемь клипов, конечные координаты, консервативные границы отсечения, отсутствие растяжения, замыкание циклов, удержание всех четырёх лап, подъём/контакт/возврат ударной лапы, смерть/возрождение и независимость клонов. Для опорных интервалов измеренный дрейф чистого клипа ниже 0,0011 м модели. Переходы движения/поворота проверяются при 30/60 FPS. Сетевые правила и размещение принадлежат отдельному изменению карты.

В Chrome на отдельном статическом preview `127.0.0.1:4838` просмотрен именно экспортированный GLB: Idle, Walk, Run, Attack на фазах 0,36 и 0,68, Death на последнем кадре. Материалы и встроенная текстура загрузились; лапы, пасть и корпус сохраняют форму, труп ложится на бок. Скриншоты браузера зафиксированы в ходе проверки; `renders/bear.png` — отдельный Blender-рендер, не подмена браузерного доказательства.

Это авторская стилизация, а не захват движения живого медведя. Нет физической шерсти, ragdoll или runtime IK по склонам; короткий Run не изображает высокоскоростной галоп. Смешивание/резкий сетевой поворот ещё могут давать небольшое скольжение. Эта проверка не измеряет FPS большого стада и не подтверждает production.

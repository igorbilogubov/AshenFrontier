# Иконки предметов — 15 сентября 2026

15 прозрачных PNG 256×256 в `public/game/item-icons/`, используемых рюкзаком, слотами, карточкой предмета и примерочной. Десять основ воина имеют отдельные изображения; одинаковые экземпляры одной основы используют одну иконку независимо от случайных статов. Цвет качества остаётся на рамке и в тексте.

Источник десяти вещей и топора — меши из поставляемого `ashen-warrior-equipment-v1.glb`; изображения корпуса лучника/мага — из `ashen-archer-v1.glb` / `ashen-mage-v1.glb`. Доспех показан торсом без головы/кистей и обуви, головные уборы и пары сапог отрендерены отдельно. Это студийное освещение: тон изображения может отличаться от лесной сцены. Blender рендерит существующую геометрию и текстуры, новые модели персонажей не создаются.

Для старого лука и посоха повторены текущие процедурные силуэты и материалы из `public/game/character.ts`: отдельного GLB оружия пока нет. Для старых предметов без definitionId выбирается изображение по слоту/классу, для старого надетого оружия воина учитывается переключение меч/топор. У старых предметов качества не имеют отдельных моделей. Для пустых слотов и характеристик сохранены контурные подсказки, а не изображения предметов.

Генератор `scripts/blender/render_item_icons.py` читает GLB и **перезаписывает только** PNG этого каталога и `build-report.json` рядом с этим README. Исходные Blend/FBX/GLB не меняются. Рендер Cycles 32 samples, AgX, прозрачный фон; камера подстраивается к размеру вещи, мечи/кольцо поворачиваются широкой стороной.

Из корня проекта:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python scripts/blender/render_item_icons.py
npm run check
npm test
```

Затем проверить настоящий игровой инвентарь и `/game/equipment-preview.html` в браузере. Тест проверяет наличие всех 15 PNG, размеры/alpha и отдельное изображение для каждой основы воина; визуальную корректность подтверждает осмотр.

Происхождение персонажей/одежды — Adobe Mixamo; права не меняются от рендера иконок. Собственные оружие и украшения происходят из генераторов проекта. См. [ASSETS.md](../../../ASSETS.md) и [модели классов](../../characters/mixamo-classes-v1/README.md). Сборочный отчёт содержит только идентификаторы ассетов, имена частей и размер файлов, без героев или ключей.

Добавлены 20 отдельных PNG для двух коллекций каждого класса. Их генерирует `scripts/blender/render_class_item_icons.py`, используя общий студийный рендер из `render_item_icons.py` и новые `ashen-archer-equipment-v1.glb` / `ashen-mage-equipment-v1.glb`. Скрипт перезаписывает только эти 20 PNG и отдельный `art/characters/class-equipment-v1/icon-report.json`; прежние 15 PNG не изменяет.

# Вход и выбор персонажа

Локальное изменение от 16 сентября 2026. Публикация отдельно от реализации.

- Вход через Google открывается ссылкой `/auth/google`. При отсутствии конфигурации кнопка скрыта и объясняется, что вход ещё недоступен; гостевого обхода нет.
- После входа всегда показан выбор героя: пять карточек, имя, класс и уровень. Пустые места открывают создание; сервер проверяет лимит пяти. После создания герой выбран, но вход в мир выполняется отдельной кнопкой.
- Создание: имя до 18 символов, один из трёх неизменяемых классов. Список и данные аккаунта поступают с `/api/account`, создание — `/api/characters`.
- WebSocket отправляет только `{type:'join',protocol:3,heroId}`. Авторизация идёт через HttpOnly cookie. Ключи героя не читаются/не передаются, копирование ключей и форма их ввода удалены; устаревшие локальные `frontier-token:` очищаются.
- Второе игровое окно получает ошибку сервера и остаётся на выборе героя; первое продолжает играть. Повторная попытка доступна вручную. Сетевой обрыв повторно подключает только выбранного героя. Терминальная ошибка после входа возвращает на экран аккаунта с объяснением.
- Меню «Аккаунт» находится сверху справа и не сдвигает HUD. «Выбор персонажа» закрывает соединение и перезагружает страницу, чтобы корректно загрузить модель нового класса. Выход отзывает сессию через `/auth/logout`. Открытие инвентаря/характеристик не затронуто.
- Стресс-сцена использует выделенный `/api/stress-session`, доступность которого определяет серверная изоляция; обычная страница не создаёт тестовых аккаунтов.

Проверки ветки: TypeScript не обнаружил ошибок frontend, кроме ожидаемого несовпадения protocol3 с ещё не объединённым shared/types protocol2. Координатор запускает общий check/tests и браузерный сценарий после объединения backend. Реальный Google-вход требует серверной OAuth-конфигурации; интерфейс не заявляет её готовность.

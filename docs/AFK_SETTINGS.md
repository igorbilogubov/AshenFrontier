# Сохраняемые настройки автоохоты — 15 сентября 2026

Серверный контракт, PostgreSQL-сохранение и панель настроек объединены в `main` и опубликованы в `20260915-camp-afk-01` (`76a38ec`). Интерфейс проверен в локальном браузере; на публичном сервере изменение настроек подтверждено после переподключения прежнего QA-героя. [Выкладка](../DEPLOYMENT.md), [проверки](../QA.md).

`afkPreferences` хранится у героя и возвращается только в `state.self`. Режим `self.afk` остаётся временным: сохранение настроек, переподключение и рестарт не включают автоохоту автоматически. Команда `{type:'afkPreferences',preferences}` принимает полный объект; приватное событие `preferencesSaved {ok,message?}` сообщает результат. Сервер отклоняет неполные поля, неверные типы, дубли редкостей/навыков, навыки чужого класса и значения вне границ. Обновление настроек само по себе не останавливает активную автоохоту.

```ts
interface AfkPreferences {
  pickupGold:boolean;
  pickupRarities:number[]; // любая выборка из 0, 1, 2
  hpPotion:{enabled:boolean;belowPercent:number};
  manaPotion:{enabled:boolean;belowPercent:number};
  skillOrder:SkillId[]; // любая выборка четырёх навыков класса, порядок важен
  basicAttackFallback:boolean;
  radiusPercent:number;
}
```

Новый герой и прежний герой без этого поля получают: сбор золота и редкостей 0/1/2, HP-зелье ниже 35%, MP-зелье ниже 25%, навыки 1 затем 2, обычную атаку при недоступности навыков и 100% допустимого радиуса спота. Панель позволяет задать порог зелья 5–95%; серверный контракт принимает целый процент 1–99; `enabled:false` выключает его расход. Радиус перемещения — 25–100% радиуса отмеченного спота, но не выходит за физическую границу героя. При уменьшении радиуса во время активного режима герой идёт к центру. Сервер может забрать стопку за краем радиуса движения, если герой дотягивается до неё без выхода за границу.

AFK подбирает только личное золото при `pickupGold:true` и только личные вещи с выбранной редкостью при свободном рюкзаке. Игнорируемые стопки остаются на земле до обычного срока жизни; AFK продолжает бой при полном рюкзаке или отключённых фильтрах. Радиус ограничивает движение к цели и добыче, но дальний навык может поражать цель за границей перемещения из допустимой позиции.

Сервер перебирает выбранные навыки по кольцу, начиная с текущей позиции. Он пропускает недоступные по мане, откату или дистанции и двигает указатель только после успешного каста. Если ни один навык сейчас не подходит, обычная атака разрешена только при `basicAttackFallback:true`. Пустой `skillOrder` допустим. Урон, попадания, откаты, расход маны/зелий и награды используют существующие серверные методы боя. Ручное движение, удар и навык по-прежнему останавливают AFK; нейтральные сетевые пакеты и сохранение панели не останавливают.

Миграция PostgreSQL 3 добавляет `heroes.afk_preferences jsonb` транзакционно. Существующие строки, ID/броски предметов, сундук, золото и счётчики зелий не переписываются; старые герои читаются с настройками по умолчанию для их сохранённого класса. Экономический снимок включает настройки, чтобы сервер подтвердил изменение в базе до следующего сетевого состояния. `/health` проверяет наличие схемы 3 и сообщает фактическую версию. Проверки выполняются на временных PostgreSQL и свободном сетевом порту.

# Звук

18 сентября 2026. Локальная реализация; публикация отдельно.

Игра больше не молчит. Клиент `public/game/sounds.ts` поднимает Web Audio после первого клика или клавиши (браузер не даёт звук раньше). Клипы — CC0 OGG в `public/game/sounds/`, происхождение в [art/audio/README.md](../art/audio/README.md).

Кнопка «Звук» и клавиша **M** рядом с «Добыча». Состояние в `localStorage ashen-sound` (`on`/`off`), по умолчанию включено. При выключении усиление мастера = 0.

События сервера:

- удар / получение урона / промах / золото / вещь / лечение / уровень / смерть / убийство / портал / костёр / магазин / сундук / кузнец
- заточка: успех и срыв по тексту `notice`

Новая атака героя даёт взмах (воин/лучник) или магию (маг и навыки). Шаги только у живого героя вне AFK. Во время автоохоты боевые клипы тише и с паузой между одинаковыми, чтобы не греметь.

Музыки нет: только короткие эффекты.

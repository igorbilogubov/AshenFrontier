# Интерфейс зелий в рюкзаке

Зелья отображаются стопками рядом с ненадетыми вещами. Число ячеек рассчитывается по вещам и непустым стопкам; при миграции рюкзака сверх 16 ячеек интерфейс показывает все сохранённые предметы. Значок стопки и подсказка показывают тип, восстановление, количество и способ назначения.

Перетаскивание бутылки из рюкзака на Q или W отправляет `assignConsumable` с ID вида зелья. Бутылка остаётся в рюкзаке. Любой вид можно назначить в любой слот, включая пустой или временно недоступный. Щелчок по Q/W и соответствующая клавиша отправляют `useConsumable` только при доступном запасе, ресурсе и откате. Отдельные значки количества показывают ноль даже после расхода последней бутылки; сохранённая привязка остаётся видимой до повторной покупки или замены.

Покупка у торговца использует прежнюю команду `buyConsumable` с видом `hp`/`mana`. Новая стопка требует свободной ячейки; пополнение существующей стопки не требует её. Продажа и перенос бутылок в сундук пока не поддерживаются сервером. В браузере на отдельном сервере проверены реальное перетаскивание HP на W и MP на Q без расхода, сохранение раскладки после перезагрузки, лечение по W и расход маны по Q, совпадение счётчиков рюкзака и панели во время AFK. Подробности в [QA](../QA.md).

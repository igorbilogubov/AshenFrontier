# Управление мышью

Актуально для локального пакета от 16 сентября 2026. Новое решение пользователя заменяет движение только при удержании ЛКМ.

| Действие | Управление |
| --- | --- |
| Идти в точку с обходом препятствий | ЛКМ по земле; отпускать можно сразу |
| Подойти к противнику и повторять обычные удары | ЛКМ по противнику |
| Удары без сближения | Shift + ЛКМ; удержание повторяет удар |
| Назначенные навыки | 1, 2, 3, 4 и ПКМ |
| Назначенные зелья | Q / W |
| Подобрать один ближайший объект | Пробел; каждое нажатие — один объект |
| Ходьба / бег | R или кнопка в HUD |
| Онлайн-автоохота | F |
| Книга навыков и талантов | K |
| Характеристики / рюкзак | C / I |
| Подписи добычи | Z |
| Зум фиксированной камеры | Колесо мыши |
| Отмена движения / подхода | Escape или новая команда |

ЛКМ по добыче, торговцу, сундуку или порталу сохраняет приоритет взаимодействия. На платном портале появляется список назначений с ценами и требованиями уровня. Shift + ЛКМ имеет приоритет над взаимодействием. ПКМ в рюкзаке по-прежнему надевает/снимает вещь; пятый навык запускается ПКМ по игровому полотну.

Клиент передаёт конечную точку, а сервер проверяет локацию, проходимость и строит ограниченный A* маршрут. Отпускание ЛКМ не отменяет маршрут. Нейтральные сетевые пакеты поддерживают соединение, не сбрасывая путь. Потеря фокуса, смерть и отключение прекращают движение; наведение без нажатия не поворачивает героя. WASD/стрелки и движение по миникарте не вводились.

Обычная атака по выбранной цели продолжается до её смерти/недоступности или новой команды. Урон, расстояние и скорость атак определяет сервер. Удержание ПКМ повторяет пятый навык по его откату; канал прекращается после отпускания. Назначение выполняется в книге навыков, как для слотов 1–4.

Пробел выбирает ближайшую доступную личную вещь или стопку золота в пределах 6 м и запускает серверный подход. Финальная дистанция подбора — 1,4 м. Удержание пробела не собирает всё подряд; чужой дроп, препятствия и вместимость рюкзака сохраняют проверки. Z скрывает только подписи и не мешает пробелу или клику по предмету.

Проверки актуальных серверных команд — тесты порталов/управления; браузерные доказательства — QA.md. Исторические проверки старой схемы удержания не являются доказательством новой схемы.

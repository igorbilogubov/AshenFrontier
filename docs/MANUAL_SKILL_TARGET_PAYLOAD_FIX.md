# Ручные навыки и координаты курсора — 15 сентября 2026

Локальное исправление `NetworkGame.skill`: координаты `aim.target` передаются серверу только для дождя стрел и метеора. Остальные десять навыков сохраняют направление `yaw` и необязательный `targetId`, но не отправляют точку области. Серверные правила навыков не меняются.

Причина: общий обработчик сцены передаёт точку курсора при любом ручном навыке. Ранее сетевой метод копировал весь объект в пакет; сервер корректно отклонял точку у обычных навыков сообщением «Неверная точка навыка». Ошибка блокировала ручные удары воина и другие навыки без области.

Регрессия вызывает настоящий `NetworkGame.skill`, перехватывает его сериализованный пакет и передаёт в `World.command`. Все 12 навыков проверяются с выбранным мобом (включая ID 0) и только с курсором: сервер принимает навык и списывает правильную ману. Отдельно проверены сохранение координат двух областей, отсутствие изменения объекта прицеливания, необязательное прицеливание и отключённое соединение.

`npm run check` и целевой тест (2/2, 24 сочетания навык/прицеливание) прошли. Полный `npm test` — 212/212, без пропусков, на временной PostgreSQL. Браузерная проверка и публикация не входят в доказательства этого коммита; общий сервер не перезапускался.

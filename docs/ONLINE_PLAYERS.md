# Игроки онлайн

Каждый снимок мира содержит `onlinePlayers`: список реально подключённых героев со всего мира. Для каждой записи передаются только `id`, имя, класс, уровень и текущая `LocationId`; данные аккаунта, сеть и инвентарь не входят в контракт.

Список не заменяет локальный `players`: он остаётся ограниченным текущей локацией и нужен для отрисовки. Клиент очищает глобальный список при обрыве соединения, поэтому панель не показывает устаревшие данные между переподключениями.

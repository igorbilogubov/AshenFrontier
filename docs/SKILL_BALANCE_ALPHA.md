# Проверка навыков: 25-й уровень

Локальный аудит 16 сентября 2026, после серверной правки `ca51675` и каталога региональных вещей `1484bcd`. В этой постановке ни один класс не превосходит оба других вдвое: воин лидирует по неподвижной одиночной цели в ближнем контакте, маг — по четырём плотным целям. Разница между лучшими результатами классов составляет около 25–29% без зелий. Это начальная проверка, а не доказательство равного PvP, равной скорости прокачки или готовой экономики.

## Воспроизведение

Нужны Node.js 24 и актуальная объединённая ветка с навыками, талантами и региональными вещами:

```sh
npm ci
npm run build
node scripts/balance/skill-alpha.mjs > artifacts/skill-balance-alpha.json
```

Папку `artifacts/` при необходимости создать заранее. Скрипт работает непосредственно через серверный `World`, без HTTP, аккаунтов, PostgreSQL и обычных сохранений. Выводит JSON с условиями, 60 базовыми замерами и шестью замерами талантов. На промежуточной изолированной ветке использовался TypeScript emit при незавершённой интеграции соседних клиентских файлов; это не выдаётся за успешный общий `npm run check`. После объединения координатор выполняет общие проверки отдельно.

Условия фиксированы:

- 25-й уровень, шесть зелёных предметов своего класса из каталога Пустошей, середина каждого диапазона. Равный ранг вещей, не одинаковые численные бонусы разных классов.
- 125 вручную вложенных статов. Воин: 65 силы / 20 ловкости / 25 живучести / 15 энергии; лучник: 0 / 65 / 35 / 25; маг: 0 / 20 / 40 / 65. Это три разумных примера, не оптимизация всех возможных билдов.
- Базовые замеры без талантов: у каждого остаются четыре свободных очка. Проверяются только открытые на 25-м уровне атаки/каналы без отдельного cooldown.
- Персонаж стоит на месте. Цель — неподвижный волк с 1 000 000 HP, без ответных атак. Для четырёх целей используется компактный прямоугольник 1×1,1 м на расстоянии 1,3–2,3 м впереди героя. Это выгодная постановка для массовых навыков и ближнего боя.
- Настоящие попадания/промахи и серверный урон; генератор случайности с seed 619, шаг мира 0,05 с. DPS считается по потерянному HP всех целей.
- `ceiling`: 60 секунд, мана возвращается к максимуму каждый тик. Показывает потенциальный урон и расход при достаточном снабжении, а не обычный режим игры.
- `natural`: 300 секунд с полным начальным запасом, обычной регенерацией и без зелий. Каждый тик делается попытка навыка; если он не может начаться и нет текущей атаки/канала, используется обычный удар. Конечная средняя включает стартовый запас MP, поэтому это ещё не бесконечный ресурсный режим.

`mpPerSecond` — валовой расход, до компенсации регенерацией. Для канала учитываются оплаченные тики луча. `casts` предназначен для дискретных атак, не для числа тиков канала.

## Одиночная цель

| Навык | DPS при достаточной MP | Расход MP/с | DPS за 300 с без зелий |
| --- | ---: | ---: | ---: |
| Воин: Выпад | 287,47 | 14,33 | 248,48 |
| Воин: Мощный удар | 261,67 | 11,60 | 246,41 |
| Воин: Кровавый разрез | 269,32 | 12,90 | 259,37 |
| Лучник: Прицельный выстрел | 219,27 | 11,67 | 220,54 |
| Лучник: Ядовитая стрела | 216,20 | 11,83 | 226,18 |
| Маг: Ледяное копьё | 206,27 | 14,00 | 206,97 |
| Маг: Чародейский луч | 173,07 | 11,08 | 185,27 |

Кровотечение и яд можно повторять как основной навык: они обновляют длительность существующего эффекта, не складываются бесконечно и не откладывают следующий тик. Отдельный серверный контактный тест после `ca51675` проверяет, что повторение DoT-навыка не проваливается ниже 85% выбранной основной атаки, а чередование с ней не даёт более 15% преимущества над лучшим одиночным вариантом в его условиях. Это не универсальная граница для всех уровней/вещей.

У слабого против одиночной цели массового навыка результат `natural` может оказаться выше `ceiling`: в первом варианте значительную часть времени используется более сильный бесплатный обычный удар. Это следствие явно включённого fallback, а не повышение урона при нехватке маны.

Ближний бой с неограниченным снабжением имеет заметное преимущество в этой компактной группе. При обычной регенерации маг дольше поддерживает массовые атаки. Рассечение/Вихрь требуют контакта, огонь/молния доступны с дистанции; входящий урон, движение и потеря контакта здесь намеренно не измерены. По этим числам нельзя обещать одинаковый опыт в час на настоящих спотах.

## Таланты и найденные ошибки

Проба четырёх очков: воин и лучник берут по два ранга точности и урона одиночных навыков; маг — по два ранга урона и экономии луча.

| Проба | DPS без талантов → с талантами | Расход MP/с без → с |
| --- | ---: | ---: |
| Мощный удар | 261,67 → 294,15 | 11,60 → 11,60 |
| Прицельный выстрел | 219,27 → 247,45 | 11,67 → 11,67 |
| Чародейский луч | 173,07 → 182,90 | 11,08 → 10,42 |

Эффекты этих веток работают. У мага часть очков направлена в экономию, поэтому эти три строки не являются сравнением одинакового бюджета чистого урона. Первое ключевое умение ветки доступно после восьми вложенных обычных очков и ещё одного очка на само умение: не раньше 42-го уровня. На 25-м уровне проверяются только обычные узлы.

В ходе аудита найдены и уже исправлены серверной правкой `ca51675`:

1. «Широкий веер» менял параметр области, который не использовали реальные стрелы. Теперь фактический угол залпа берётся из `effectiveSkill`; есть регрессионная проверка.
2. Приземление прыжка воина использовало жёсткие коэффициенты урона/радиуса и не ограничивало число целей. Теперь используются эффективные параметры навыка, ближайшие цели и предел четыре; есть регрессионная проверка.

Параллельный серверный прогон также усилил прямую часть повторяемых кровотечения/яда с 0,86 до 1,12 и снизил их расход до 9/10 MP. Таблицы выше пересчитаны после этой правки.

## Что проверить дальше

- Луч: в этой постановке без талантов примерно на 16% слабее копья, зато расходует примерно на 21% меньше MP. У него короче дальность и требуется поддержание канала; полезность выбора нужно проверить в настоящем бою и с веткой Чародея, прежде чем менять коэффициенты.
- «Источник маны» на 45-м уровне возвращает максимум 24 MP при стоимости 18 и интервале 30 с: чистая прибавка всего до 0,2 MP/с до учёта времени каста. Группы пока отсутствуют; ценность этого слота в текущем одиночном режиме сомнительна. Нужна отдельная настройка, а не обещание полноценного группового бафа.
- Предел поглощения Манового щита — минимум из 80 и 40% максимального HP. При росте вещей фиксированные 80 уменьшают его относительную пользу; сравнить на высоких уровнях с другими защитными кнопками.
- Таланты восстановления HP следуют общему правилу регенерации вне боя. Подсказку стоит уточнить, чтобы игрок не ожидал лечения во время неподвижной автоохоты.
- Следующий обязательный этап — одинаковые по рангу билды на настоящих спотах: расход зелий, смерти, XP/минуту, дальняя/разреженная группа, элита, сохранение контакта и отсутствие маны. Затем отдельные PvP-коэффициенты. Текущий аудит не моделирует эти режимы и не доказывает равный баланс всех 36 навыков.

Ни публикации, ни изменений обычных героев/БД этот аудит не выполняет. Числа являются стартовой точкой для дальнейших игровых проверок.

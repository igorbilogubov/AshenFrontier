# UI книги навыков и талантов

Локальная реализация от 16 сентября 2026. Этот документ описывает клиентскую часть согласованной системы из `SKILL_BUILDS_PROPOSAL.md`; публикация и production этим изменением не выполнялись.

## Поведение

- Книга открывается кнопкой **«Навыки»** или клавишей **K**. Само открытие и закрытие не останавливает бой, движение или автоохоту и не меняет нижний HUD.
- Вкладка навыков показывает двенадцать навыков текущего класса в порядке открытия: 1, 3, 5, 8, 10, 14, 18, 22, 27, 32, 38 и 45 уровни. Закрытый навык виден вместе с требуемым уровнем, но его нельзя назначить.
- Четыре активных слота соответствуют клавишам 1–4. Навык назначается перетаскиванием либо выбором карточки и последующим выбором слота. Повторное назначение переносит навык, дубликаты не создаются.
- Подсказка показывает эффективные параметры с учётом черновика талантов: расход MP, перезарядку, дальность, радиус, число целей и длительность эффекта, если параметр применим.
- Вкладка талантов содержит три ветки класса: пять малых талантов по два ранга и один итоговый. Бюджет начинается на 10 уровне, растёт на одно очко каждые четыре уровня и ограничен 20 очками. Итоговый талант требует восемь очков в своей ветке; одновременно разрешён один итоговый талант.
- Сброс талантов бесплатный: кнопка очищает таланты только в локальном черновике. Изменение вступает в силу после серверного применения у костра.
- Три пресета называются «Охота», «Босс» и «PvP». Сохранение записывает текущую применённую сборку; загрузка просит сервер применить сохранённый пресет. Пустые пресеты недоступны.

## Серверный контракт

Клиент читает `skillBuild`, `buildRevision` и `skillPresets` из собственного снимка. Изменения отправляются командами `buildApply`, `buildSavePreset` и `buildLoadPreset`; результат приходит как `buildResult`. До подтверждения повторные команды блокируются. Сообщение сервера показывается без подмены локальной общей ошибкой.

Просмотр и редактирование черновика доступны в любой точке. Кнопка применения доступна только при соединении, живом герое и в безопасной зоне. Принятое сервером применение само останавливает автоохоту; простое открытие книги её не меняет. Перезарядки остаются привязанными к ID навыка.

Нижний HUD читает четыре ID из применённой серверной сборки. Пустой слот остаётся пустым. Удержание 1–4 повторяет обычный навык; Чародейский луч отправляет импульсы примерно каждые 120–150 мс и `skillStop` при отпускании клавиши, потере фокуса или отмене ввода.

Настройки автоохоты показывают только навыки из применённых четырёх слотов. Навыки перемещения исключены. Порядок сохраняется отдельно через существующий контракт настроек автоохоты.

## Файлы и проверка

- `public/game/skillbook-ui.ts` — состояние черновика, назначения, таланты, пресеты и серверные ответы.
- `public/game/skillbook.css` — широкая книга, компактные desktop/mobile раскладки и подсказки.
- `public/index.html` — доступная структура панели и кнопка K.
- `public/game/interface.ts`, `scene.ts`, `network.ts`, `afk-settings-ui.ts` — динамический HUD, ввод, канал, сеть и фильтр автоохоты.
- `public/game/action-icons.ts` — отдельные читаемые силуэты для 24 новых действий.
- `test/skill-build-ui.test.mjs` — каталог, таланты, иконки и обязательная структура страницы.

Общая проверка после объединения с серверной и графической частями: `npm run check`, `npm test`, затем браузер на desktop и телефонном viewport. В браузере нужно подтвердить назначение drag/click, блокировки уровней и бюджета, изменение эффективных параметров, настоящий отказ сервера вне безопасной зоны, применение у костра, остановку автоохоты только после применения и отпускание поддерживаемого луча.

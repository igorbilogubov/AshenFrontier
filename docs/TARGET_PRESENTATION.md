# Представление выбранной цели

Локальный модуль `public/game/target-presentation.ts` выводит имя по центру экрана в существующей панели, видимое серверное HP и лёгкое кольцо под выбранным мобом, торговцем или другим героем. Панель скрывается при отсутствии цели; у торговца без HP нет пустой шкалы. Кольцо следует переданным координатам, отличается по размеру/цвету для моба, NPC и героя, не добавляет полного экранного эффекта или обработки кадра.

У моба под HP есть четыре иконки *категорий возможной добычи*: золото, оружие, броня (доспех/шлем/сапоги) и аксессуары (кольцо/амулет). Правила взяты из `loot-rules.ts`, `location.ts` и текущего `equipment-items.ts`: личное золото достаётся каждому подходящему участнику убийства; шанс **одной** вещи — 10% для волка/кабана/медведя и 40% для вожака. Категории вещей выбираются уже внутри этого одного шанса. Все текущие найденные вещи имеют редкость 1 («Необычный»); интерфейс не обещает редкие предметы или конкретную основу. Цвет золотой для золота и зелёный для текущих вещей, с подготовленными стилями следующих редкостей. Будущие категории появятся только после изменения настоящего серверного каталога и правил.

Курсор `/game/cursors/ashen-pointer.svg` — светлая собственная стрелка с тёмным контуром; интерактивные области получают бронзовый вариант. Текстовые поля сохраняют системный I-beam. Координатор подключает CSS после `scene.css`, выбирает мировые объекты в `scene.ts`/`world-interactions.ts` и вызывает возвращённую функцию `bindTargetPresentation(scene)` с выбранной целью или `null` при исчезновении/смене региона. Модуль не меняет правила серверного подхода, атаки и наград. Проверка браузерной читаемости на реальном viewport выполняется после интеграции этих обработчиков.

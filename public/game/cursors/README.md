# Игровой указатель

Два оригинальных SVG курсора созданы для Ashen Frontier 15 сентября 2026. Форма — читаемая светлая стрелка с бронзовым краем и тёмной окантовкой на лесном фоне; вариант `ashen-interact.svg` подсвечивает интерактивные кнопки и мировые подписи. Размер 32 × 32 px, точка нажатия `(2, 2)`. Оба файла векторные и редактируются вручную; внешние игровые ассеты не использованы. Текстовые поля сохраняют системный I-beam.
